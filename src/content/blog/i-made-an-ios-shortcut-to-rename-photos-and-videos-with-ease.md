I always found it strange that iOS does not let you properly rename photos and videos. You can edit almost everything. But file names. Still locked down.

I searched for apps. I tested workarounds. Nothing felt clean. The only method that worked was uploading media to Dropbox, renaming it there, then saving it back to Photos. It works. But it is slow and annoying. 😤

After doing this a few too many times, I decided to fix my own problem.

So I made an iOS Shortcut called Rename iOS Media 🚀
It lets you rename any photo or video directly from your Photos app. No third party apps. No cloud services. Everything stays on your device.

The flow is simple. You select a photo or video. The Shortcut asks for a new name. It saves the media back with that name. Done in seconds.

This is not a Shortcut you will run every day. But when you need it, it feels essential. Organizing travel photos. Renaming videos before editing. Cleaning files before sharing. That moment when you think, why can I not rename this. This Shortcut has your back 😌

I uploaded it to RoutineHub so anyone can use it. You can download it from the link: [https://routinehub.co/shortcut/2603/](https://routinehub.co/shortcut/2603/)​

The Shortcut also supports translations. Russian language support is provided by @DevilMachine and the [Russian community](https://t.me/iosshortcut) 🇷🇺

If you run into any bugs or issues, please report them via the Shortcut. Feedback helps me improve it.

Apple might add this feature someday. Until then, I built my own solution. And honestly, it works really well. ✅
