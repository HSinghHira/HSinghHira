## Quick install guide for the newbies real quick 👇

1. Open your terminal and paste this magic line:\\

```
curl - fsSL https://bun.sh/install | bash
```

1. Restart your terminal (or just run `source ~/.bashrc` / `source ~/.zshrc`)
2. Done bestie ✨ Type bun --version to flex on everyone

Works on macOS, Linux, and even Windows (WSL). If you’re on Windows without WSL, just go to [https://bun.sh](https://bun.sh) and grab the .exe 🤍

After that just use:

* `bun i` → instead of `npm install`
* `bun run dev` → instead of `npm run dev`
* `bunx` → instead of `npx`

Welcome to the fast lane babes 🚀🐰💨
